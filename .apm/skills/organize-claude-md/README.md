# organize-claude-md

肥大化した CLAUDE.md を整理して 50 行未満に保つスキル。

## 解決する課題

CLAUDE.md は毎セッション全文がコンテキストに載るため、肥大化はそのままコンテキスト予算の浪費になる。またファイル特化・ディレクトリ特化・スタイル規則が一枚に混在すると保守も難しくなる。

## アプローチ

各ルールを「ファイル特化(→ `.claude/rules/` + paths glob)」「ディレクトリ特化(→ サブディレクトリの CLAUDE.md)」「linter で強制できるスタイル規則(→ 削除して lint コマンド 1 行に置換)」「タスクランナーコマンド(→ 代表数個に圧縮)」「全体事項(→ ルート据え置き)」に分類し、変更計画をユーザーに提示・承認を得てから適用する。
