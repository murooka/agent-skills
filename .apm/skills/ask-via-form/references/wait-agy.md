# agy(Antigravity CLI)での待ち方

agy のコマンドは、実行から数秒でバックグラウンドのタスクに移る。タスクが終わると通知されるはずだが、
通知が届かないという報告がある。**通知を当てにせず、自分で様子を見に行く。**

```bash
python3 <スキルのディレクトリ>/scripts/ask.py wait --session <id> --timeout 240
```

- バックグラウンドのタスクに移ったら、タスクの状態を確認するツールで、終わったかどうかを見に行く。確認の間隔はタイマーで 1〜2 分空ける
- 終了コード `3`(タイムアウト)なら、同じコマンドを実行し直す。人はまだ回答中
- **完了の通知を受けたように見えても、タスクの状態と出力を実際に確かめてから回答として扱う。** 実行中のタスクについて、完了の通知を思い込んで作り上げてしまう不具合が報告されている
- `wait` は何度実行し直しても安全。「受け取り済みです」と言われたのに出力が手元にないときは、`history` で読み直す
- ヘッドレス(`-p`)では `--print-timeout`(既定 5 分)で打ち切られ、人が答え終わるまで待てない。このスキルは対話モードで使う
