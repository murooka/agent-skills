# Claude Code での待ち方

Bash ツールで `run_in_background: true` を指定して `wait` を実行する。`--timeout` は付けない。

```bash
python3 <スキルのディレクトリ>/scripts/ask.py wait --session <id>
```

- 人が送信するとコマンドが終わり、Claude Code が自動で起こしてくれる。起こされたら、コマンドの出力と終了コードを読む
- **前面では実行しない。** Bash ツールの実行時間には上限(既定で最大 10 分)があり、人が答え終わる前に切れる
- 待っている間に `sleep` やポーリングで様子を見に行かない。終了の通知が来るまで、ほかの作業(調査のサブエージェントを動かす、など)をしてよい
- 終了コード `0` なら回答、`1` ならエラーメッセージを読んで対処する
- 待っている間に聞きたいことが増えたら、同じフォーム id で `post` し直してよい。動いている `wait` はそのままで、止めなくてよい
