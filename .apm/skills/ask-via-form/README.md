# ask-via-form

AI エージェントが人に設問をまとめて聞くとき、CLI でのやり取りの代わりに、ブラウザのフォームで回答してもらうスキル。

## 解決する課題

grilling や grill-with-docs のようなスキルは、1 ラウンドで何問も設問を出す。CLI で答えようとすると、人は設問を 1 つずつ引用して
回答を打ち込むことになり、手間がかかるうえに設問と回答の対応がずれやすい。かといって、AI にその都度 Web 画面を作らせると
トークンを大量に消費する。

## アプローチ

画面とサーバをスキルに同梱し、AI はフォーム定義(JSON)を書くだけで済むようにする。

- 同梱の `scripts/ask.py` が、ローカル(127.0.0.1)にフォームの画面を立ち上げる。依存は Python 3 の標準ライブラリだけ
- 回答形式は、選択肢の有無・単一か複数か・自由記述の要否の組み合わせで表す。推奨回答と理由を添えられ、人はボタン 1 つで推奨を採れる
- 人は設問ごとに、回答のほか「保留」と「差し戻し(設問そのものへの疑問や異議)」を返せる。未回答が残っていても送信できる
- 1 つのタブでセッションが続き、次のフォームは同じ画面に積み重なる。送信済みのフォームも後から直せ、変更は次の送信で AI に届く
- AI には、設問タイトルと選んだ選択肢の見出しを含む Markdown で回答が返る。AI がフォーム定義と照らし合わせなくても意味が読める
- フォームを出す `post` と、送信を待つ `wait` を分けている。Claude Code はバックグラウンド実行の終了通知で待ち、
  Codex や agy は `wait` を繰り返し実行して待つ。`wait` は何度実行し直しても安全

設計の用語は [CONTEXT.md](./CONTEXT.md) にまとめている。

## 使い方

明示的に指示されたときだけ起動する。

```
/grill-with-docs 〜について相談したい。設問はフォームで聞いて
```

毎回指示するのが面倒なら、CLAUDE.md や AGENTS.md に常設の指示を書いておく。

```markdown
## 設問の聞き方

grilling など、設問を何問も出すスキルを使うときは、設問を ask-via-form スキルでフォームに出して聞く。
```

claude.ai/code などのリモート環境では、人のブラウザからフォームに届かないので使えない。

## 依存

- Python 3.9 以上(標準ライブラリのみ)
- macOS または Linux(ファイルのロックに `fcntl` を使う)
- ブラウザ
